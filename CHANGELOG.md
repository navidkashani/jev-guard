## [1.1.0] - 2026-09-25

### Added

- React settings screen (Overview, Settings, Calibration) in the VeronaLabs admin style.
- REST routes under `spamlens/v1` for settings, test connection, calibration, statistics, re-check and the Pending sweep.
- "Remove key" on the settings screen.
- Tests for the REST routes, the container and uninstall; JavaScript tests for the calibration maths.
- CI: coding standards, PHPUnit matrix, front-end build, Plugin Check, version check; release workflow that deploys to WordPress.org.

### Changed

- Renamed from Jev Guard to SpamLens. The slug, folder, text domain and main file are now `spamlens`, options and meta use the `spamlens_` prefix, hooks are `spamlens_*` (were `jev_guard_*`), the constant is `SPAMLENS_API_KEY` and the REST namespace is `spamlens/v1`. Settings and statistics from Jev Guard are copied on first activation.
- Plugin structure follows the VeronaLabs Forge starter: `src/` with a service container and providers, Composer PSR-4 autoloading generated by WP Scoper into `packages/`.
- Classes moved to `SpamLens\Service\…` namespaces. Custom integrations now implement `SpamLens\Service\Integrations\Integration`.
- admin-ajax handlers replaced by REST routes.
- Author is VeronaLabs.

### Removed

- `Update URI` header (not allowed on WordPress.org).

## [1.0.0] - 2026-09-21

### Added

- Checks comments, WooCommerce reviews, pingbacks and Contact Form 7 submissions.
- Providers: TypeSafe AI, Vercel AI Gateway, OpenRouter and custom endpoints.
- Three-tier decision (spam / hold / allow) with hold rules for borderline, on-topic-but-spammy and abusive comments.
- Retry queue re-checks comments the service could not classify within 20 minutes.
- "Page context" setting (Title only / Standard / Extended) controls how much of the page is sent; `spamlens_post_context` filter.
- The text of password-protected, private and unpublished pages is never sent.
- A request the provider rejects as too large is retried once without the page text.
- Calibration tool, statistics, and a "SpamLens" column in the comments list with decision, category and hold reason.
