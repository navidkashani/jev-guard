# Security

Please report vulnerabilities privately through GitHub:
https://github.com/navidkashani/jev-guard/security/advisories/new

Do not open a public issue for a security problem. You will get an acknowledgement within 7 days, and a fix or a status update after that.

Only the latest 1.x release is supported with security fixes.

Problems on the provider side (TypeSafe AI, Vercel AI Gateway, OpenRouter) should be reported to that provider; this plugin only sends requests to them.
